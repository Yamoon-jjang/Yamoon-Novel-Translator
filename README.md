# 야문 Novel Translator

중국어 · 일본어 · 영어로 된 TXT 소설과 문서를 한국어로 번역하는 Windows 프로그램입니다.
Gemini, OpenAI, 내 PC의 로컬 LLM(Ollama 등)을 원하는 순서로 써서 막힌 문단까지 이어 번역하고,
인명 · 용어 · 인물 말투를 책 전체에서 같게 유지합니다.

원문을 새로 쓰거나 순화하지 않고 뜻과 수위, 문체를 그대로 옮기는 번역을 목표로 합니다.
미성년자가 관련된 성적 내용만 번역에서 제외합니다.

## 주요 기능

- **빠짐없는 번역** — 문단마다 번호를 붙여 보내고 같은 번호가 그대로 돌아왔는지 확인합니다. 문단이 사라지거나 순서가 바뀌지 않습니다.
- **여러 번역 엔진** — Gemini · OpenAI · 로컬 LLM 중 1~3개를 골라 순서를 정합니다. 앞 엔진이 거부한 문단은 다음 엔진이 이어서 번역합니다.
- **같은 이름으로** — 인명 · 지명을 자동으로 뽑아 확정 용어집으로 고정하고, 책마다 쌓이는 공용 용어집을 다음 책에도 씁니다.
- **인물 말투표** — 누가 누구에게 반말 · 존댓말을 쓰는지 정해 두어 같은 두 사람의 말투가 흔들리지 않게 합니다.
- **끊겨도 이어서** — 조금씩 저장하며 번역하므로 중간에 멈추거나 PC가 꺼져도 번역한 곳부터 이어집니다.
- **폴더 통째로** — 폴더 안의 TXT 파일을 순서대로 끝까지 번역합니다. 하위 폴더 구조도 유지합니다.
- **한국어 소설 재정비** — 이미 번역된 한국어 TXT의 직역투 · 어순 · 대사 흐름을 로컬 LLM으로 자연스럽게 다듬습니다.
- **원본 보호** — 원본 파일은 바꾸지 않고 결과를 `파일이름.ko.txt`로 따로 저장합니다.

## 권장 번역 엔진: 내 PC의 로컬 LLM

이 프로그램은 Gemini · OpenAI도 쓸 수 있지만, **소설 번역에는 내 PC에서 돌리는 로컬 LLM(Ollama)을 가장 권합니다.**

| | 로컬 LLM | Gemini · OpenAI |
|---|---|---|
| 비용 | 없음 (전기료 정도) | 사용량만큼 요금 |
| 원고 | PC 밖으로 나가지 않음 | 서비스 서버로 전송 |
| 하루 한도 · 서버 차단 | 없음 | 한도와 서비스 정책 적용 |
| 성인 장면 · 폭력 묘사 | 모델에 따라 끝까지 번역 | 정책상 거부되는 경우가 잦음 |
| 속도 | 그래픽카드에 따라 다름 | 빠름 |

클라우드 엔진은 빠르고 품질도 좋지만, 성인 소설이나 수위 높은 장면은 서비스 정책에 따라 요청이 거부되곤 합니다.
프로그램이 거부된 문단을 다음 엔진으로 넘겨 끝까지 이어 가지만, 마지막 엔진까지 거부하면 그 부분은 원문으로 남습니다.

### 성인 소설이라면: 거부 해제(abliterated) 모델

원문의 수위를 그대로 옮기려면, 응답 거부 성향을 줄인 **거부 해제(abliterated) 로컬 모델**을 쓰는 것이 가장 확실합니다.
이런 모델을 쓰면 번역은 물론 인명 · 용어 추출, 인물 말투표, 한국어 소설 재정비까지 **모든 기능이 거부 없이 끝까지 동작**합니다.

- **권장 모델: Gemma 4 26B 이상의 거부 해제(abliterated) 모델.** 문장이 가장 자연스러워,
  개발 중 실제 번역과 재정비를 이 모델로 확인했습니다. 16GB 그래픽카드에서 동작합니다.
  그래픽카드 메모리가 부족하면 Gemma 4 12B도 쓸 수 있습니다(가볍고 안정적이지만 문장 품질은 26B보다 낮음).
- 권하는 엔진 순서
  - 성인 소설: **로컬 LLM 1순위** (필요하면 Gemini를 보조로)
  - 일반 소설: Gemini 1순위 + 로컬 LLM 보조 — 빠르게 번역하다가 막힌 문단만 로컬 LLM이 이어 번역
- 설치부터 모델 등록까지 단계별 안내는 `사용설명서.html`의 **11장 로컬 LLM**에 있습니다.

> 어떤 모델을 쓰든 **미성년자가 관련된 성적 내용은 프로그램이 번역에서 제외**합니다. 모델의 거부 성향과 상관없이 적용되는 규칙입니다.
> 모델의 선택과 사용, 각 모델의 라이선스 준수는 사용자의 책임입니다.

## 내려받기와 실행

1. 오른쪽 **Releases**에서 최신 `Yamoon-Novel-Translator-…-Windows-Portable.zip`을 받습니다.
2. zip 파일을 오른쪽 클릭 → 속성 → **차단 해제**에 체크한 뒤 원하는 폴더에 풉니다. (설치 과정은 없습니다)
3. `NovelTranslator.exe`를 실행합니다. Windows가 "PC 보호" 창을 띄우면 **추가 정보 → 실행**을 누릅니다. 코드 서명을 하지 않은 개인 제작 프로그램이라 나오는 안내입니다.
4. 오른쪽 위 **API 설정**에서 번역 엔진을 준비합니다. 로컬 LLM은 Ollama를 켜 두면 등록된 모델 목록을 자동으로 불러오고, Gemini · OpenAI는 API 키를 넣습니다.

자세한 사용법은 프로그램 폴더의 `사용설명서.html`을 보세요.

- 지원: Windows 10 / 11 (64비트)
- 번역 엔진 이용료와 약관은 각 서비스(Google Gemini, OpenAI)를 따릅니다. 로컬 LLM은 비용 없이 내 PC에서 실행됩니다.

## 소스에서 빌드하기

Windows에서 Python 3.12로 빌드합니다.

```bat
cd app
python -m pip install -r requirements-build.txt
build_windows.bat
```

`build_windows.bat`은 자동 테스트와 점검을 모두 통과해야 `app\dist\NovelTranslator\`에 실행 파일을 만듭니다.
GitHub Actions(`.github/workflows/build.yml`)도 같은 과정으로 빌드하며, 새 버전이 main에서 모든 점검을 통과하면 Releases에 배포본을 자동으로 올립니다.
